# Katselmointipyyntö: ML-KEM-ytimien K-yleistys (aether-one PR #24)

## Tausta
aether-one on SystemVerilog-oppimisprototyyppi: ML-KEM (FIPS 203) ja ML-DSA-65
RTL:nä, TAU-kehys (Wishbone, audit-loki, watchdog). Päätös 2026-11-15: ML-KEM-512
(K=2) → ML-KEM-768 (K=3), jotta ML-KEM ja ML-DSA-65 ovat samassa NIST-kategoriassa 3.

Tässä muutoksessa viisi orkestrointiydintä ja Wishbone-kääre muutettiin
K-parametrisiksi. Aiemmin niissä oli K=2-kovakoodauksia (esim. `s_vec[n_ctr[0]]`,
kiinteät 768/800/1632-tavuiset leveydet, kaksi kiinteää alimoduuli-instanssia).
Oletus pysyy K=2:na.

Simulaattori: Icarus Verilog (iverilog -g2012). Primitiivimoduulit (Keccak, NTT,
SampleNTT, CBD, Compress, ByteEncode/Decode) ovat ennallaan eivätkä ole mukana;
niiden portit näkyvät instansseista. pqc_sha3_256/pqc_shake256: MAX_BLOCKS
136-tavuista lohkoa, msg_in leveys 8*136*MAX_BLOCKS, padding sisäinen.

## Mitä on jo todennettu (älä toista, käytä lähtökohtana)
- NIST ACVP (usnistgov/ACVP-Server 975de31), synteesikelpoisia ytimiä vasten:
  ML-KEM-512 ja ML-KEM-768, KeyGen 25/25, Encaps 25/25, Decaps 10/10 (5 hylkäystä).
  Negatiivikontrolli: yksi heksamerkki muutettu tiedoston viimeisessä rivissä → FAIL.
- Koko ketju KeyGen→Encaps→Decaps Wishbonen kautta, K=2 ja K=3, satunnaissyötteet.
- 8 olemassa olevaa K=2-TAU-testiä ennallaan PASS.
- Verilator --lint-only ilman virheitä K=2 ja K=3 (varoituksia: leveydet, int-vertailut).

## Viite: FIPS 203 taulukko 2 ja johdetut koot
| sarja | k | η1 | η2 | du | dv | ek | dk | c |
|---|---|---|---|---|---|---|---|---|
| ML-KEM-512 | 2 | 3 | 2 | 10 | 4 | 800 | 1632 | 768 |
| ML-KEM-768 | 3 | 2 | 2 | 10 | 4 | 1184 | 2400 | 1088 |
| ML-KEM-1024 | 4 | 2 | 2 | 11 | 5 | 1568 | 3168 | 1568 |
ek = 384k+32, dk = 768k+96, c = 32(du·k+dv).

## Mitä pyydän
Testit menevät läpi K=2 ja K=3. Etsi siksi asioita, joita ne EIVÄT paljasta:
1. Virheet, jotka näkyisivät vain K=4:llä (ML-KEM-1024 kääntyy, ei todennettu):
   laskurien leveydet, lohkomäärät (H_BLOCKS, J_BLOCKS), du=11/dv=5-polut, word_sel (11 bittiä) kääreessä.
2. Parametrien johtaminen: onko jokainen oletusarvo FIPS 203:n mukainen kaikilla k? Voiko johdetun
   parametrin (EK_BYTES ym.) ylikirjoitus hiljaa rikkoa jotain?
3. Synteesiin liittyvät ongelmat, jotka simulaatio ohittaa: muuttuja-indeksit taulukkoihin, for-silmukat
   always_ff:ssä, kombinatoriset polut, generate-if testipenkissä.
4. Testien heikkoudet: kattaako negatiivikontrolli oikeasti kaikki tapaukset? Voiko testipenkki (mlkem_acvp_tb.sv)
   raportoida PASS väärin (esim. $fscanf-virhe, X-arvot, `===`-vertailut, decaps match_out-tarkistus)?
   Tarkistaako gen_mlkem_acvp_vectors.py oikeat asiat?
5. Muu, mikä on mielestäsi virhe. Erottele selvästi: (a) varma virhe rivinumeroineen,
   (b) epäily, jonka tarkistaminen vaatii lisätietoa, (c) tyylihuomio.

Älä ehdota testien heikentämistä tai NIST-vektorien muuttamista. Älä keksi tuloksia: sinulla ei ole
simulaattoria eikä repoa, vain tämä aineisto.

```
  16  // K-yleistys (2026-11-15): K=2 (ML-KEM-512) ja K=3 (ML-KEM-768)
  17  // todennettu NIST ACVP -vektoreilla. K=4 (ML-KEM-1024) kaantyy, ei
  18  // todennettu. Johdetut leveydet (EK_BYTES, DK_BYTES, H_BLOCKS) ovat
  19  // parametreja vain siksi, etta niita voi kayttaa porttileveyksissa:
  20  // niita EI ole tarkoitus ylikirjoittaa.
  21  //
  22  // SEKVENSSI (yleinen K):
  23  // 1. SHA3-512(d||K) -> rho, sigma
  24  // 2. SampleNTT(rho,i,j) x4 (KxK) -> A[i][j]
  25  // 3. PRF+SamplePolyCBD(sigma,N) x4 (2K) -> s_vec[i], e_vec[i]
  26  // 4. NTT-forward x4 (2K) -> s_hat[i], e_hat[i]
  27  // 5. Matriisikertolasku+summaus: t_hat[i] = sum_j(A[i][j]*s_hat[j]) + e_hat[i]
  28  // 6. ByteEncode12(t_hat) + rho -> ek
  29  // 7. ByteEncode12(s_hat) -> dkPKE
  30  // 8. H(ek)=SHA3-256(ek), kokoa dk = dkPKE||ek||H(ek)||z
  31  //
  32  // TAMA ON TUTKIMUSPROTOTYYPPI (fpga/tau/) - EI VIELA tuotanto-
  33  // integraatiota. Testattu Icarus Verilogilla, EI VIELA synteesi-
  34  // testattu ECP5:lla.
  35  
  36  `timescale 1ns/1ps
  37  
  38  module pqc_mlkem_keygen_core #(
  39      parameter int COEFF_W = 16,
  40      parameter int SPAD_AW = 9,
  41      parameter int K = 2,
  42      parameter int ETA1 = (K == 2) ? 3 : 2,
  43      parameter int DKPKE_BYTES = 384*K,
  44      parameter int EK_BYTES = 384*K + 32,
  45      parameter int DK_BYTES = 768*K + 96,
  46      parameter int H_BLOCKS = EK_BYTES/136 + 1
  47  )(
  48      input  logic clk,
  49      input  logic reset,
  50  
  51      input  logic start,
  52      input  logic [255:0] d_seed,
  53      input  logic [255:0] z_seed,
  54  
  55      output logic done,
  56      output logic [8*EK_BYTES-1:0] ek_out,
  57      output logic [8*DK_BYTES-1:0] dk_out,
  58  
  59      // TILAPAINEN debug-ulostulo taman osittaisen version testausta
  60      // varten - poistetaan kun koko sekvenssi on valmis.
  61      output logic [255:0] debug_rho,
  62      output logic [255:0] debug_sigma,
  63      output logic [256*COEFF_W-1:0] debug_A00,
  64      output logic [4:0] debug_state
  65  );

  67    // --- Alimoduulit (kaikki jo todennettuja, uudelleenkaytettyja) ---
  68    logic ntt_start, stage_done, bank_conflict_detected;
  69    logic [7:0] ntt_count, ntt_pair_dist;
  70    logic ntt_mode;
  71    logic [SPAD_AW-1:0] base_addr_lane0, base_addr_lane1;
  72    logic [COEFF_W-1:0] zeta_lane0, zeta_lane1;
  73    logic ntt_load_valid, ntt_read_en, ntt_read_valid;
  74    logic [7:0] ntt_load_addr, ntt_read_addr;
  75    logic [COEFF_W-1:0] ntt_load_data, ntt_read_data;
  76  
  77    pqc_ntt_stage_banked #(.COEFF_W(COEFF_W), .SPAD_AW(SPAD_AW), .FPGA_BRINGUP(1)) ntt_dut (
  78      .clk(clk), .reset(reset), .start(ntt_start), .count(ntt_count),
  79      .pair_dist(ntt_pair_dist), .mode(ntt_mode),
  80      .base_addr_lane0(base_addr_lane0), .base_addr_lane1(base_addr_lane1),
  81      .zeta_lane0(zeta_lane0), .zeta_lane1(zeta_lane1),
  82      .stage_done(stage_done), .bank_conflict_detected(bank_conflict_detected),
  83      .load_valid(ntt_load_valid), .load_addr(ntt_load_addr), .load_data(ntt_load_data),
  84      .read_en(ntt_read_en), .read_addr(ntt_read_addr), .read_valid(ntt_read_valid), .read_data(ntt_read_data)
  85    );
  86  
  87    // --- NTT-aikataulun ROM (M4-MLKEM-ORCH-001): 64 merkintaa (taso 6
  88    // + full_schedule.txt), pakattu 64-bittisiksi sanoiksi:
  89    // {length[8], base0[9], zeta0[16], base1[9], zeta1[16]} ---
  90    logic [71:0] ntt_schedule_rom [0:63];
  91    initial begin
  92      $readmemh("fpga/tau/mlkem_ntt_schedule_rom.memh", ntt_schedule_rom);
  93    end
  94  
  95    logic sha512_start, sha512_done;
  96    logic [8*72-1:0] sha512_msg_in;
  97    logic [511:0] sha512_out;
  98    pqc_sha3_512 #(.MAX_BLOCKS(1)) sha512_dut (
  99      .clk(clk), .reset(reset), .start(sha512_start),
 100      .msg_in(sha512_msg_in), .msg_len_bytes(16'd33),
 101      .digest_out(sha512_out), .done(sha512_done)
 102    );
 103  
 104    logic sha256_start, sha256_done;
 105    logic [8*136*H_BLOCKS-1:0] sha256_msg_in;
 106    logic [255:0] sha256_out;
 107    pqc_sha3_256 #(.MAX_BLOCKS(H_BLOCKS)) sha256_dut (
 108      .clk(clk), .reset(reset), .start(sha256_start),
 109      .msg_in(sha256_msg_in), .msg_len_bytes(EK_BYTES[15:0]),
 110      .digest_out(sha256_out), .done(sha256_done)
 111    );
 112  
 113    logic samplentt_start, samplentt_done, samplentt_err;
 114    logic [255:0] samplentt_rho;
 115    logic [7:0] samplentt_j, samplentt_i;
 116    logic [256*COEFF_W-1:0] samplentt_out;
 117    logic [15:0] sn_acc, sn_rej, sn_xof;
 118    pqc_samplentt #(.XOF_BYTES(1008)) samplentt_dut (
 119      .clk(clk), .reset(reset), .start(samplentt_start),
 120      .rho(samplentt_rho), .byte_j(samplentt_j), .byte_i(samplentt_i),
 121      .a_hat(samplentt_out), .accepted_count(sn_acc), .rejected_count(sn_rej),
 122      .xof_bytes_consumed(sn_xof), .done(samplentt_done), .error_exhausted(samplentt_err)
 123    );
 124  
 125    logic cbd1_start, cbd1_done;
 126    logic [255:0] cbd1_seed;
 127    logic [7:0] cbd1_n;
 128    logic [256*COEFF_W-1:0] cbd1_out;
 129    pqc_prf_samplepolycbd #(.ETA(ETA1)) cbd1_dut (
 130      .clk(clk), .reset(reset), .start(cbd1_start),
 131      .seed_s(cbd1_seed), .counter_n(cbd1_n), .f_out(cbd1_out), .done(cbd1_done)
 132    );
 133  
 134    logic [256*COEFF_W-1:0] mntt_f, mntt_g, mntt_h;
 135    pqc_multiplyntts #(.COEFF_W(COEFF_W)) mntt_dut (.f_hat(mntt_f), .g_hat(mntt_g), .h_hat(mntt_h));
 136  
 137    logic [256*COEFF_W-1:0] padd_a, padd_b, padd_sum;
 138    pqc_polyadd #(.COEFF_W(COEFF_W)) padd_dut (.a_in(padd_a), .b_in(padd_b), .sum_out(padd_sum));
 139  
 140    logic [256*12-1:0] benc12_in [0:K-1];
 141    logic [8*384-1:0] benc12_out [0:K-1];
 142    for (genvar g = 0; g < K; g++) begin : g_benc12
 143      pqc_byteencode_dparam #(.D(12)) benc12 (.f_in(benc12_in[g]), .b_out(benc12_out[g]));
 144    end
 145  
 146    // M4-MLKEM-ORCH-001 debug-korjaus (2026-07-19): pqc_byteencode_dparam
 147    // odottaa kertoimet TIIVIISTI pakattuina 12 bittiin/kerroin (256*12
 148    // bittia), MUTTA oma polynomiedustuksemme kayttaa 16 bittia/kerroin
 149    // (256*16 bittia, COEFF_W). Suora leveyseroinen assign katkaisisi/
 150    // sekoittaisi pakkauksen - taman vuoksi tarvitaan eksplisiittinen
 151    // uudelleenpakkaus (kukin kertoimen oma 12-bittinen ARVO poimitaan
 152    // ja pakataan TIIVIISTI).
 153    function automatic [256*12-1:0] repack16_to_12(input logic [256*COEFF_W-1:0] wide);
 154      for (int k = 0; k < 256; k++) begin
 155        repack16_to_12[k*12 +: 12] = wide[k*COEFF_W +: COEFF_W];
 156      end
 157    endfunction
 158  
 159    // --- Tallennusrekisterit ---
 160    logic [255:0] rho, sigma;
 161    logic [256*COEFF_W-1:0] A [0:K-1][0:K-1];
 162    logic [256*COEFF_W-1:0] s_vec [0:K-1], e_vec [0:K-1];
 163    logic [256*COEFF_W-1:0] s_hat [0:K-1], e_hat [0:K-1], t_hat [0:K-1];
 164    logic [255:0] H_ek;
 165    logic [8*EK_BYTES-1:0] ek_reg;
 166    logic [8*DK_BYTES-1:0] dk_reg;
 167  
 168    // --- Paatilakone: askellaskuri, joka kayy lapi tasmalleen saman
 169    // sekvenssin kuin testipenkin oma initial-lohko. ---
 170    typedef enum logic [4:0] {
 171      S_IDLE, S_RESET_SHA512, S_START_SHA512, S_WAIT_SHA512,
 172      S_RESET_SNTT, S_START_SNTT, S_WAIT_SNTT, S_SNTT_NEXT,
 173      S_RESET_CBD, S_START_CBD, S_WAIT_CBD, S_CBD_NEXT,
 174      S_NTT_FWD_LOAD, S_NTT_FWD_SCHED_SETUP, S_NTT_FWD_SCHED_START, S_NTT_FWD_SCHED_WAIT,
 175      S_NTT_FWD_READ, S_NTT_FWD_READ_WAIT, S_NTT_FWD_NEXT,
 176      S_MATMUL, S_MATMUL_NEXT,
 177      S_ENCODE_T, S_ENCODE_S,
 178      S_RESET_SHA256, S_START_SHA256, S_WAIT_SHA256,
 179      S_ASSEMBLE, S_DONE
 180    } state_e;
 181    state_e state, return_state;
 182  
 183    logic [3:0] i_ctr, j_ctr;
 184    logic [3:0] n_ctr;
 185    logic [3:0] fwd_ctr;
 186    logic [3:0] mm_i, mm_j;
 187    logic [256*COEFF_W-1:0] mm_acc;
 188    logic [7:0] load_idx, read_idx;
 189    logic [5:0] sched_idx;
 190    logic [256*COEFF_W-1:0] fwd_poly_in, fwd_poly_out;
 191  
 192    always_ff @(posedge clk) begin
 193      ntt_start <= 1'b0;
 194      sha512_start <= 1'b0;
 195      sha256_start <= 1'b0;
 196      samplentt_start <= 1'b0;
 197      cbd1_start <= 1'b0;
 198      done <= 1'b0;
 199  
 200      if (reset) begin
 201        state <= S_IDLE;
 202        i_ctr <= 4'd0; j_ctr <= 4'd0; n_ctr <= 4'd0;
 203      end else begin
 204        case (state)
 205          S_IDLE: begin
 206            if (start) begin
 207              sha512_msg_in <= '0;
 208              sha512_msg_in[255:0] <= d_seed;
 209              sha512_msg_in[263:256] <= K[7:0];
 210              state <= S_START_SHA512;
 211            end
 212          end
 213  
 214          S_START_SHA512: begin
 215            sha512_start <= 1'b1;
 216            state <= S_WAIT_SHA512;
 217          end
 218          S_WAIT_SHA512: begin
 219            if (sha512_done) begin
 220              rho   <= sha512_out[255:0];
 221              sigma <= sha512_out[511:256];
 222              i_ctr <= 4'd0; j_ctr <= 4'd0;
 223              state <= S_START_SNTT;
 224            end
 225          end
 226  
 227          // --- SampleNTT KxK kertaa ---
 228          S_START_SNTT: begin
 229            samplentt_rho <= rho; samplentt_i <= {4'b0,i_ctr}; samplentt_j <= {4'b0,j_ctr};
 230            samplentt_start <= 1'b1;
 231            state <= S_WAIT_SNTT;
 232          end
 233          S_WAIT_SNTT: begin
 234            if (samplentt_done) begin
 235              A[i_ctr][j_ctr] <= samplentt_out;
 236              state <= S_SNTT_NEXT;
 237            end
 238          end
 239          S_SNTT_NEXT: begin
 240            if (j_ctr == K-1) begin
 241              j_ctr <= 4'd0;
 242              if (i_ctr == K-1) begin
 243                i_ctr <= 4'd0; n_ctr <= 4'd0;
 244                state <= S_START_CBD;
 245              end else begin
 246                i_ctr <= i_ctr + 4'd1;
 247                state <= S_START_SNTT;
 248              end
 249            end else begin
 250              j_ctr <= j_ctr + 4'd1;
 251              state <= S_START_SNTT;
 252            end
 253          end
 254  
 255          // --- PRF+SamplePolyCBD 2K kertaa: ensin K s_vec, sitten K e_vec ---
 256          S_START_CBD: begin
 257            cbd1_seed <= sigma; cbd1_n <= {4'b0,n_ctr};
 258            cbd1_start <= 1'b1;
 259            state <= S_WAIT_CBD;
 260          end
 261          S_WAIT_CBD: begin
 262            if (cbd1_done) begin
 263              for (int q = 0; q < K; q++) begin
 264                if (n_ctr == q)     s_vec[q] <= cbd1_out;
 265                if (n_ctr == K + q) e_vec[q] <= cbd1_out;
 266              end
 267              state <= S_CBD_NEXT;
 268            end
 269          end
 270          S_CBD_NEXT: begin
 271            if (n_ctr == 2*K-1) begin
 272              fwd_ctr <= 4'd0;
 273              load_idx <= 8'd0;
 274              fwd_poly_in <= s_vec[0];
 275              state <= S_NTT_FWD_LOAD;
 276            end else begin
 277              n_ctr <= n_ctr + 4'd1;
 278              state <= S_START_CBD;
 279            end
 280          end
 281  
 282          // --- NTT-forward: 2K kertaa (s_vec[0..K-1], e_vec[0..K-1])
 283          // -> s_hat[0..K-1], e_hat[0..K-1].
 284          // Kayttaa ytimen omaa FPGA_BRINGUP-rajapintaa (load_valid/
 285          // load_addr/load_data, read_en/read_addr/read_valid/
 286          // read_data) - EI hierarkkista suoraa kirjoitusta (joka EI
 287          // ole synteesikelpoinen). ---
 288          S_NTT_FWD_LOAD: begin
 289            ntt_load_valid <= 1'b1;
 290            ntt_load_addr  <= load_idx;
 291            ntt_load_data  <= fwd_poly_in[load_idx*COEFF_W +: COEFF_W];
 292            if (load_idx == 8'd255) begin
 293              sched_idx <= 6'd0;
 294              state <= S_NTT_FWD_SCHED_SETUP;
 295            end else begin
 296              load_idx <= load_idx + 8'd1;
 297            end
 298          end
 299  
 300          // M4-MLKEM-ORCH-001 debug-korjaus (2026-07-19): parametrit
 301          // (pair_dist/base_addr/zeta/count) asetetaan OMASSA,
 302          // ERILLISESSA syklissaan ENNEN start-pulssia - sama periaate
 303          // kuin jo todistetussa suorassa testissa (joka kayttaa
 304          // "parametrit; @(posedge clk); start<=1;" -kuviota, EI aseta
 305          // molempia SAMALLA syklilla).
 306          S_NTT_FWD_SCHED_SETUP: begin
 307            ntt_load_valid <= 1'b0;
 308            begin
 309              logic [71:0] entry;
 310              entry = ntt_schedule_rom[sched_idx];
 311              ntt_pair_dist   <= entry[57:50];
 312              base_addr_lane0 <= entry[49:41];
 313              zeta_lane0      <= entry[40:25];
 314              base_addr_lane1 <= entry[24:16];
 315              zeta_lane1      <= entry[15:0];
 316              ntt_count       <= entry[65:58];
 317            end
 318            ntt_mode  <= 1'b0;
 319            state <= S_NTT_FWD_SCHED_START;
 320          end
 321  
 322          S_NTT_FWD_SCHED_START: begin
 323            ntt_start <= 1'b1;
 324            state <= S_NTT_FWD_SCHED_WAIT;
 325          end
 326  
 327          S_NTT_FWD_SCHED_WAIT: begin
 328            if (stage_done) begin
 329              if (sched_idx == 6'd63) begin
 330                read_idx <= 8'd0;
 331                state <= S_NTT_FWD_READ;
 332              end else begin
 333                sched_idx <= sched_idx + 6'd1;
 334                state <= S_NTT_FWD_SCHED_SETUP;
 335              end
 336            end
 337          end
 338  
 339          S_NTT_FWD_READ: begin
 340            // Esita osoite (read_idx), odota YKSI sykli ennen luvun
 341            // tarkistusta - vastaa tasmalleen jo toimivaksi todistettua
 342            // Wishbone-lukupolkua (yksi pyynto kerrallaan, ei
 343            // perakkaisia paallekkaisia lukuja).
 344            state <= S_NTT_FWD_READ_WAIT;
 345          end
 346  
 347          S_NTT_FWD_READ_WAIT: begin
 348            if (ntt_read_valid) begin
 349              for (int q = 0; q < K; q++) begin
 350                if (fwd_ctr == q)     s_hat[q][read_idx*COEFF_W +: COEFF_W] <= ntt_read_data;
 351                if (fwd_ctr == K + q) e_hat[q][read_idx*COEFF_W +: COEFF_W] <= ntt_read_data;
 352              end
 353              if (read_idx == 8'd255) begin
 354                state <= S_NTT_FWD_NEXT;
 355              end else begin
 356                read_idx <= read_idx + 8'd1;
 357                state <= S_NTT_FWD_READ;
 358              end
 359            end
 360          end
 361  
 362          S_NTT_FWD_NEXT: begin
 363            if (fwd_ctr == 2*K-1) begin
 364              mm_i <= 4'd0; mm_j <= 4'd0;
 365              mm_acc <= '0;
 366              state <= S_MATMUL;
 367            end else begin
 368              fwd_ctr <= fwd_ctr + 4'd1;
 369              load_idx <= 8'd0;
 370              for (int q = 0; q < K; q++) begin
 371                if (fwd_ctr + 4'd1 == q)     fwd_poly_in <= s_vec[q];
 372                if (fwd_ctr + 4'd1 == K + q) fwd_poly_in <= e_vec[q];
 373              end
 374              state <= S_NTT_FWD_LOAD;
 375            end
 376          end
 377  
 378          // --- Matriisikertolasku+summaus: t_hat[i] = sum_j(A[i][j]*
 379          // s_hat[j]) + e_hat[i]. mntt_dut/padd_dut ovat TAYSIN
 380          // kombinatorisia (ei clk/reset/start/done) - vain rekisteroity
 381          // akkumulointi tarvitaan. ---
 382          S_MATMUL: begin
 383            mm_acc <= padd_sum;  // mm_acc + mntt_h (ks. combinational wiring alla)
 384            if (mm_j == K-1) begin
 385              mm_j <= 4'd0;
 386              state <= S_MATMUL_NEXT;
 387            end else begin
 388              mm_j <= mm_j + 4'd1;
 389            end
 390          end
 391  
 392          S_MATMUL_NEXT: begin
 393            // mm_acc sisaltaa nyt sum_j(A[mm_i][j]*s_hat[j]) - lisaa
 394            // e_hat[mm_i], talleta t_hat[mm_i].
 395            t_hat[mm_i] <= final_sum;
 396            if (mm_i == K-1) begin
 397              state <= S_ENCODE_T;
 398            end else begin
 399              mm_i <= mm_i + 4'd1;
 400              mm_acc <= '0;
 401              state <= S_MATMUL;
 402            end
 403          end
 404  
 405          // --- ByteEncode12(t_hat) + rho -> ek, ByteEncode12(s_hat) -> dkPKE ---
 406          S_ENCODE_T: begin
 407            for (int q = 0; q < K; q++) ek_reg[q*8*384 +: 8*384] <= benc12_out[q];
 408            ek_reg[8*DKPKE_BYTES +: 256] <= rho;
 409            state <= S_ENCODE_S;
 410          end
 411  
 412          S_ENCODE_S: begin
 413            for (int q = 0; q < K; q++) dk_reg[q*8*384 +: 8*384] <= benc12_out[q];  // dkPKE (K*384 tavua)
 414            sha256_msg_in <= '0;
 415            sha256_msg_in[8*EK_BYTES-1:0] <= ek_reg;
 416            state <= S_START_SHA256;
 417          end
 418  
 419          S_START_SHA256: begin
 420            sha256_start <= 1'b1;
 421            state <= S_WAIT_SHA256;
 422          end
 423  
 424          S_WAIT_SHA256: begin
 425            if (sha256_done) begin
 426              H_ek <= sha256_out;
 427              state <= S_ASSEMBLE;
 428            end
 429          end
 430  
 431          S_ASSEMBLE: begin
 432            // dk = dkPKE || ek || H(ek) || z (FIPS 203:n kiintea rakenne)
 433            dk_reg[8*DKPKE_BYTES +: 8*EK_BYTES]     <= ek_reg;
 434            dk_reg[8*(DKPKE_BYTES+EK_BYTES) +: 256]    <= H_ek;
 435            dk_reg[8*(DKPKE_BYTES+EK_BYTES+32) +: 256] <= z_seed;
 436            state <= S_DONE;
 437          end
 438  
 439          S_DONE: begin
 440            done <= 1'b1;
 441            state <= S_IDLE;
 442          end
 443  
 444          default: state <= S_IDLE;
 445        endcase
 446      end
 447    end
 448  
 449    // M4-MLKEM-ORCH-001 debug-korjaus (2026-07-19): read_en/read_addr
 450    // TAYTYY olla KOMBINATORISIA (ei rekisteroityja) - sama periaate
 451    // kuin jo toimivaksi todistetussa Wishbone-lukupolussa
 452    // (pqc_ntt_wishbone_wrapper.sv: "assign read_en = ...", EI
 453    // rekisteroity <=). Ytimen oma read_valid/read_data tulevat YHDEN
 454    // SYKLIN viiveella - read_idx_captured tallentaa MIKA read_idx oli
 455    // silloin kun VASTAAVA data lopulta saapuu.
 456    assign ntt_read_en   = (state == S_NTT_FWD_READ) || (state == S_NTT_FWD_READ_WAIT);
 457    assign ntt_read_addr = read_idx;
 458  
 459    logic [256*COEFF_W-1:0] final_sum;
 460  
 461    // Matriisikertolasku: A[mm_i][mm_j] * s_hat[mm_j], akkumuloi mm_acc:iin.
 462    // padd_b vaihtuu: S_MATMUL:ssa mntt_h (uusi kertolaskutermi),
 463    // S_MATMUL_NEXT:ssa e_hat[mm_i] (lopullinen summaus).
 464    assign mntt_f = A[mm_i][mm_j];
 465    assign mntt_g = s_hat[mm_j];
 466    assign padd_a = mm_acc;
 467    assign padd_b = (state == S_MATMUL_NEXT) ? e_hat[mm_i] : mntt_h;
 468    assign final_sum = padd_sum;
 469  
 470    // ByteEncode12: S_ENCODE_T kayttaa t_hat:ia, S_ENCODE_S kayttaa s_hat:ia -
 471    // yhteiskaytto SAMOJEN kombinatoristen instanssien kanssa eri aikoina.
```

```
 458          // --- B2b-2: inverse-NTT + skaalaus u_acc[col]:lle, +e1_vec[col] -> u_vec[col] ---
 459          S_INV_U_LOAD: begin
 460            ntt_load_valid <= 1'b1;
 461            ntt_load_addr  <= inv_load_idx;
 462            ntt_load_data  <= u_acc[inv_col][inv_load_idx*COEFF_W +: COEFF_W];
 463            if (inv_load_idx == 8'd255) begin
 464              inv_sched_idx <= 6'd0;
 465              state <= S_INV_U_SCHED_SETUP;
 466            end else inv_load_idx <= inv_load_idx + 8'd1;
 467          end
 468  
 469          S_INV_U_SCHED_SETUP: begin
 470            ntt_load_valid <= 1'b0;
 471            begin
 472              logic [71:0] entry;
 473              entry = inv_schedule_rom[inv_sched_idx];
 474              ntt_count       <= entry[65:58];
 475              ntt_pair_dist   <= entry[57:50];
 476              base_addr_lane0 <= entry[49:41];
 477              zeta_lane0      <= entry[40:25];
 478              base_addr_lane1 <= entry[24:16];
 479              zeta_lane1      <= entry[15:0];
 480            end
 481            ntt_mode <= 1'b1;
 482            state <= S_INV_U_SCHED_START;
 483          end
 484  
 485          S_INV_U_SCHED_START: begin
 486            ntt_start <= 1'b1;
 487            state <= S_INV_U_SCHED_WAIT;
 488          end
 489  
 490          S_INV_U_SCHED_WAIT: begin
 491            if (stage_done) begin
 492              if (inv_sched_idx == 6'd63) begin
 493                inv_read_idx <= 8'd0;
 494                state <= S_INV_U_READ;
 495              end else begin
 496                inv_sched_idx <= inv_sched_idx + 6'd1;
 497                state <= S_INV_U_SCHED_SETUP;
 498              end
 499            end
 500          end
 501  
 502          S_INV_U_READ: state <= S_INV_U_READ_WAIT;
 503  
 504          S_INV_U_READ_WAIT: begin
 505            if (ntt_read_valid) begin
 506              raw_u[inv_read_idx*COEFF_W +: COEFF_W] <= ntt_read_data;
 507              if (inv_read_idx == 8'd255) state <= S_INV_U_SCALE;
 508              else begin
 509                inv_read_idx <= inv_read_idx + 8'd1;
 510                state <= S_INV_U_READ;
 511              end
 512            end
 513          end
 514  
 515          S_INV_U_SCALE: begin
 516            scale_in <= raw_u;
 517            state <= S_INV_U_ADD_E1;
 518          end
 519  
 520          S_INV_U_ADD_E1: begin
 521            padd_a <= scale_out;
 522            padd_b <= e1_vec[inv_col];
 523            state <= S_INV_U_NEXT;
 524          end
 525  
 526          S_INV_U_NEXT: begin
 527            u_vec[inv_col] <= padd_sum;
 528            if (inv_col == K-1) begin
 529              inv_load_idx <= 8'd0;
 530              state <= S_INV_V_LOAD;
 531            end else begin
 532              inv_col <= inv_col + 4'd1;
 533              inv_load_idx <= 8'd0;
 534              state <= S_INV_U_LOAD;
 535            end
 536          end
 537  
 538          // --- inverse-NTT + skaalaus v_acc:lle (ei viela e2/mu-lisaysta) ---
 539          S_INV_V_LOAD: begin
 540            ntt_load_valid <= 1'b1;
 541            ntt_load_addr  <= inv_load_idx;
 542            ntt_load_data  <= v_acc[inv_load_idx*COEFF_W +: COEFF_W];
 543            if (inv_load_idx == 8'd255) begin
 544              inv_sched_idx <= 6'd0;
 545              state <= S_INV_V_SCHED_SETUP;
 546            end else inv_load_idx <= inv_load_idx + 8'd1;
 547          end
 548  
 549          S_INV_V_SCHED_SETUP: begin
 550            ntt_load_valid <= 1'b0;
 551            begin
 552              logic [71:0] entry;
 553              entry = inv_schedule_rom[inv_sched_idx];
 554              ntt_count       <= entry[65:58];
 555              ntt_pair_dist   <= entry[57:50];
 556              base_addr_lane0 <= entry[49:41];
 557              zeta_lane0      <= entry[40:25];
 558              base_addr_lane1 <= entry[24:16];
 559              zeta_lane1      <= entry[15:0];
 560            end
 561            ntt_mode <= 1'b1;
 562            state <= S_INV_V_SCHED_START;
 563          end
 564  
 565          S_INV_V_SCHED_START: begin
 566            ntt_start <= 1'b1;
 567            state <= S_INV_V_SCHED_WAIT;
 568          end
 569  
 570          S_INV_V_SCHED_WAIT: begin
 571            if (stage_done) begin
 572              if (inv_sched_idx == 6'd63) begin
 573                inv_read_idx <= 8'd0;
 574                state <= S_INV_V_READ;
 575              end else begin
 576                inv_sched_idx <= inv_sched_idx + 6'd1;
 577                state <= S_INV_V_SCHED_SETUP;
 578              end
 579            end
 580          end
 581  
 582          S_INV_V_READ: state <= S_INV_V_READ_WAIT;
 583  
 584          S_INV_V_READ_WAIT: begin
 585            if (ntt_read_valid) begin
 586              raw_v[inv_read_idx*COEFF_W +: COEFF_W] <= ntt_read_data;
 587              if (inv_read_idx == 8'd255) state <= S_INV_V_SCALE;
 588              else begin
 589                inv_read_idx <= inv_read_idx + 8'd1;
 590                state <= S_INV_V_READ;
 591              end
 592            end
 593          end
 594  
 595          S_INV_V_SCALE: begin
 596            scale_in <= raw_v;
 597            state <= S_DECODE_MU_SETUP;
 598          end
 599  
 600          // --- mu_poly = Decompress(D=1)(ByteDecode(D=1)(m')) ---
 601          S_DECODE_MU_SETUP: begin
 602            scaled_v <= scale_out;
 603            bdec1_in <= m_prime_in;
 604            mu_bit_idx <= 8'd0;
 605            state <= S_DECODE_MU;
 606          end
 607  
 608          S_DECODE_MU: begin
 609            c1_d_sel <= 4'd1;
 610            c1_y_in  <= {15'b0, bdec1_out[mu_bit_idx]};
 611            state <= S_DECODE_MU_CAPTURE;
 612          end
 613  
 614          S_DECODE_MU_CAPTURE: begin
 615            mu_poly[mu_bit_idx*COEFF_W +: COEFF_W] <= c1_decompress_out;
 616            if (mu_bit_idx == 8'd255) state <= S_ADD_E2;
 617            else begin
 618              mu_bit_idx <= mu_bit_idx + 8'd1;
 619              state <= S_DECODE_MU;
 620            end
 621          end
 622  
 623          S_ADD_E2: begin
 624            padd_a <= scaled_v;
 625            padd_b <= e2_poly_out;
 626            state <= S_ADD_MU;
 627          end
 628  
 629          S_ADD_MU: begin
 630            padd_a <= padd_sum;
 631            padd_b <= mu_poly;
 632            state <= S_COMPRESS_U_SETUP;
 633          end
 634  
 635          // --- Phase B3: Compress(DU)+ByteEncode(DU) u_vec:lle,
 636          // Compress(DV)+ByteEncode(DV) v_poly:lle -> c'. Kaksivaiheinen
 637          // setup/capture-malli (sama periaate kuin kaikkialla muualla). ---
 638          S_COMPRESS_U_SETUP: begin
 639            v_poly <= padd_sum;  // viimeistellaan v_poly:n oma laskenta tassa
 640            for (int q = 0; q < K; q++) bcompu_in[q] <= u_vec[q];
 641            state <= S_COMPRESS_U;
 642          end
 643  
 644          S_COMPRESS_U: begin
 645            for (int q = 0; q < K; q++) bencu_in[q] <= bcompu_out[q];
 646            state <= S_ENCODE_U;
 647          end
 648  
 649          S_ENCODE_U: begin
 650            for (int q = 0; q < K; q++) c_prime[(q*DU*32)*8 +: DU*32*8] <= bencu_out[q];
 651            bcompv_in <= v_poly;
 652            state <= S_COMPRESS_V_SETUP;
 653          end
 654  
 655          S_COMPRESS_V_SETUP: begin
 656            state <= S_COMPRESS_V;
 657          end
 658  
 659          S_COMPRESS_V: begin
 660            bencv_in <= bcompv_out;
 661            state <= S_ENCODE_V;
 662          end
 663  
 664          S_ENCODE_V: begin
 665            c_prime[(K*DU*32)*8 +: DV*32*8] <= bencv_out;
 666            shake256_msg_in <= '0;
 667            state <= S_START_SHAKE256;
 668          end
 669  
 670          // --- Phase B4: FO-valinta. match=(c==c'), K_bar=J(z||c)=
 671          // SHAKE256(z||c,32), K_final = match ? K' : K_bar ---
 672          S_START_SHAKE256: begin
 673            shake256_msg_in[255:0] <= z_in;
 674            shake256_msg_in[256 +: 8*C_BYTES] <= c_in;
 675            shake256_start <= 1'b1;
 676            state <= S_WAIT_SHAKE256;
 677          end
 678  
 679          S_WAIT_SHAKE256: begin
 680            if (shake256_done) begin
 681              match_out <= (c_in === c_prime);
 682              K_final_out <= (c_in === c_prime) ? K_prime_in : shake256_out;
 683              state <= S_DONE;
 684            end
 685          end
 686  
 687          S_DONE: begin
 688            done <= 1'b1;
 689            state <= S_IDLE;
 690          end
 691  
 692          default: state <= S_IDLE;
 693        endcase
 694      end
 695    end
 696  
 697    // --- Litistys: sisaiset unpacked-taulukot -> paketoidut ulostuloportit ---
 698    for (genvar gi = 0; gi < K; gi++) begin : g_flat
 699      for (genvar gj = 0; gj < K; gj++) begin : g_flat_a
 700        assign A_out_flat[(gi*K+gj)*256*COEFF_W +: 256*COEFF_W] = A[gi][gj];
 701      end
 702      assign y_vec_out_flat[gi*256*COEFF_W +: 256*COEFF_W]  = y_vec[gi];
 703      assign y_hat_out_flat[gi*256*COEFF_W +: 256*COEFF_W]  = y_hat[gi];
 704      assign e1_vec_out_flat[gi*256*COEFF_W +: 256*COEFF_W] = e1_vec[gi];
 705      assign u_acc_out_flat[gi*256*COEFF_W +: 256*COEFF_W]  = u_acc[gi];
 706      assign u_vec_out_flat[gi*256*COEFF_W +: 256*COEFF_W]  = u_vec[gi];
 707    end
 708  
 709    assign ntt_read_en   = (state == S_FWD_READ) || (state == S_FWD_READ_WAIT) ||
 710                            (state == S_INV_U_READ) || (state == S_INV_U_READ_WAIT) ||
 711                            (state == S_INV_V_READ) || (state == S_INV_V_READ_WAIT);
 712    assign ntt_read_addr = ((state == S_INV_U_READ) || (state == S_INV_U_READ_WAIT) ||
 713                            (state == S_INV_V_READ) || (state == S_INV_V_READ_WAIT)) ? inv_read_idx : read_idx;
 714  
 715    // B2b-1: mntt_f/mntt_g KOMBINATORISIA, indeksoituna rekisteroidyilla
 716    // mm_j/mm_col:lla - sama, jo todistettu periaate kuin KeyGenin
 717    // omassa matriisikertolaskussa (EI rekisteroida mntt_f/mntt_g:ta
 718    // itseaan, koska mntt_h on kombinatorinen niiden pohjalta).
 719    assign mntt_f = (state == S_MATMUL_V) ? t_hat[mm_j] : A[mm_j][mm_col];
 720    assign mntt_g = y_hat[mm_j];
 721  
 722    assign v_acc_out = v_acc;
 723    assign v_poly_out = v_poly;
 724    assign c_prime_out = c_prime;
 725  
 726  endmodule
```

### hardware/pqc-rtl/m2-golden/gen_mlkem_acvp_vectors.py

```
   1  #!/usr/bin/env python3
   2  """NIST ACVP (FIPS 203) -> RTL-testipenkkien vektoritiedostot, mika
   3  tahansa ML-KEM-parametrisarja.
   4  
   5  Kaytto:
   6    gen_mlkem_acvp_vectors.py <ML-KEM-512|ML-KEM-768> <keyGen.json> \
   7        <encapDecap.json> <ulostulohakemisto>
   8  
   9  Kirjoittaa kolme tiedostoa (<sarja> = 512 tai 768):
  10    keygen_<sarja>.txt   N; per tapaus: "tcId", d, z, ek, dk
  11    encaps_<sarja>.txt   N; per tapaus: "tcId", ek, m, K, c
  12    decaps_<sarja>.txt   N; per tapaus: "tcId hylkays", dk, c, K
  13                         (sama muoto kuin fpga/tau/decaps_top_nist_vectors.txt)
  14  
  15  Heksaluvut ovat little-endian pakattuja (tavu 0 = vahiten merkitseva),
  16  kuten muissakin taman kansion vektoreissa.
  17  
  18  Jokainen tapaus ajetaan ENNEN kirjoitusta myos golden-mallin lapi
  19  (mlkem_golden.py). Jos golden-malli ja NIST eroavat, skripti
  20  keskeytyy: silloin vika on mallissa tai kenttien tulkinnassa, eika
  21  RTL-vertailu kertoisi mitaan. Kenttien pituudet tarkistetaan
  22  parametrisarjan mukaan (ek/c-sekaannus nakyy pituuserona)."""
  23  
  24  import json
  25  import os
  26  import sys
  27  
  28  sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
  29  from mlkem_golden import (mlkem_keygen_internal, mlkem_encaps_internal,
  30                            mlkem_decaps_internal)
  31  
  32  # FIPS 203, taulukko 2
  33  PARAMS = {
  34      "ML-KEM-512": dict(K=2, ETA1=3, ETA2=2, DU=10, DV=4),
  35      "ML-KEM-768": dict(K=3, ETA1=2, ETA2=2, DU=10, DV=4),
  36  }
  37  
  38  
  39  def lengths(p):
  40      k = p["K"]
  41      return dict(ek=384 * k + 32, dk=768 * k + 96,
  42                  c=32 * (p["DU"] * k + p["DV"]), K=32, m=32, d=32, z=32)
  43  
  44  
  45  def pack(b):
  46      return f"{int.from_bytes(b, 'little'):0{len(b) * 2}x}"
  47  
  48  
  49  def check_len(name, b, L, tc):
  50      if len(b) != L[name]:
  51          sys.exit(f"tcId={tc}: {name} pituus {len(b)} != {L[name]}")
  52  
  53  
  54  def main(pset, kg_path, ed_path, outdir):
  55      p = PARAMS[pset]
  56      L = lengths(p)
  57      K, E1, E2, DU, DV = p["K"], p["ETA1"], p["ETA2"], p["DU"], p["DV"]
  58      suffix = pset.split("-")[-1]
  59      kg = json.load(open(kg_path))
  60      ed = json.load(open(ed_path))
  61  
  62      rows = []
  63      for g in kg["testGroups"]:
  64          if g["parameterSet"] != pset:
  65              continue
  66          for t in g["tests"]:
  67              tc = t["tcId"]
  68              d, z = bytes.fromhex(t["d"]), bytes.fromhex(t["z"])
  69              ek, dk = bytes.fromhex(t["ek"]), bytes.fromhex(t["dk"])
  70              for n, b in (("d", d), ("z", z), ("ek", ek), ("dk", dk)):
  71                  check_len(n, b, L, tc)
  72              if mlkem_keygen_internal(d, z, K, E1) != (ek, dk):
  73                  sys.exit(f"KeyGen tcId={tc}: golden-malli != NIST")
  74              rows.append(f"{tc}\n{pack(d)}\n{pack(z)}\n{pack(ek)}\n{pack(dk)}\n")
  75      write(outdir, f"keygen_{suffix}.txt", rows)
  76  
  77      enc, dec = [], []
  78      for g in ed["testGroups"]:
  79          if g["parameterSet"] != pset:
  80              continue
  81          for t in g["tests"]:
  82              tc = t["tcId"]
  83              if g["function"] == "encapsulation":
  84                  ek, m = bytes.fromhex(t["ek"]), bytes.fromhex(t["m"])
  85                  k, c = bytes.fromhex(t["k"]), bytes.fromhex(t["c"])
  86                  for n, b in (("ek", ek), ("m", m), ("K", k), ("c", c)):
  87                      check_len(n, b, L, tc)
  88                  if mlkem_encaps_internal(ek, m, K, E1, E2, DU, DV) != (k, c):
  89                      sys.exit(f"Encaps tcId={tc}: golden-malli != NIST")
  90                  enc.append(f"{tc}\n{pack(ek)}\n{pack(m)}\n{pack(k)}\n{pack(c)}\n")
  91              elif g["function"] == "decapsulation":
  92                  dk, c, k = (bytes.fromhex(t[x]) for x in ("dk", "c", "k"))
  93                  for n, b in (("dk", dk), ("c", c), ("K", k)):
  94                      check_len(n, b, L, tc)
  95                  if mlkem_decaps_internal(dk, c, K, E1, E2, DU, DV) != k:
  96                      sys.exit(f"Decaps tcId={tc}: golden-malli != NIST")
  97                  rej = 0 if t["reason"] == "valid decapsulation" else 1
  98                  dec.append(f"{tc} {rej}\n{pack(dk)}\n{pack(c)}\n{pack(k)}\n")
  99      write(outdir, f"encaps_{suffix}.txt", enc)
 100      write(outdir, f"decaps_{suffix}.txt", dec)
 101  
 102  
 103  def write(outdir, name, rows):
 104      if not rows:
 105          sys.exit(f"{name}: ei yhtaan tapausta")
 106      path = os.path.join(outdir, name)
 107      with open(path, "w") as f:
 108          f.write(f"{len(rows)}\n")
 109          f.writelines(rows)
 110      print(f"{path}: {len(rows)} tapausta, golden-malli = NIST kaikissa")
 111  
 112  
 113  if __name__ == "__main__":
 114      if len(sys.argv) != 5:
 115          sys.exit(__doc__)
 116      main(*sys.argv[1:])
```

```
  39  if [ "${2:-}" = "--verify-source" ]; then
  40    echo "[0] NIST-lahde: haku, sha256, uudelleengenerointi..."
  41    base="https://raw.githubusercontent.com/usnistgov/ACVP-Server/$ACVP_COMMIT/gen-val/json-files"
  42    curl -sSfL -o "$TMP/kg.json" "$base/ML-KEM-keyGen-FIPS203/internalProjection.json" || exit 1
  43    curl -sSfL -o "$TMP/ed.json" "$base/ML-KEM-encapDecap-FIPS203/internalProjection.json" || exit 1
  44    echo "$KG_SHA  $TMP/kg.json" | sha256sum -c --quiet || exit 1
  45    echo "$ED_SHA  $TMP/ed.json" | sha256sum -c --quiet || exit 1
  46    mkdir -p "$TMP/gen"
  47    python3 m2-golden/gen_mlkem_acvp_vectors.py "ML-KEM-$PSET" "$TMP/kg.json" "$TMP/ed.json" "$TMP/gen" || exit 1
  48    for op in keygen encaps decaps; do
  49      if ! cmp -s "$TMP/gen/${op}_$PSET.txt" "fpga/tau/acvp/${op}_$PSET.txt"; then
  50        echo "VIRHE: fpga/tau/acvp/${op}_$PSET.txt ei vastaa NIST-lahteesta generoitua"
  51        FAILED=1
  52      fi
  53    done
  54  fi
  55  
  56  corrupt() {
  57    python3 - "$1" "$2" <<'PY'
  58  import sys
  59  lines = open(sys.argv[1]).read().split("\n")
  60  i = max(k for k, l in enumerate(lines) if l.strip())
  61  lines[i] = lines[i][:-1] + ("1" if lines[i][-1] == "0" else "0")
  62  open(sys.argv[2], "w").write("\n".join(lines))
  63  PY
  64  }
  65  
  66  # $1 = sim, $2 = vektorit, $3 = odotus (pass|fail), $4 = nimi
  67  run_case() {
  68    local out result
  69    out="$(vvp "$1" +VEC="$2" 2>&1)"
  70    if echo "$out" | grep -q "^PASS" && ! echo "$out" | grep -q "FAIL"; then result=pass; else result=fail; fi
  71    if [ "$result" = "$3" ]; then
  72      echo "  ok    $4: $(echo "$out" | grep -E '^(PASS|FAIL)' | head -1)"
  73    else
  74      echo "  VIRHE $4: odotettu $3, saatu $result"
  75      echo "$out" | grep -E "EI TASMAA|FAIL|fatal" | head -5 | sed 's/^/        /'
  76      FAILED=1
  77    fi
  78  }
  79  
  80  echo "[1] Kaannetaan (K=$K)..."
  81  OPS=(keygen encaps decaps)
  82  for op in 0 1 2; do
  83    sim="sim/acvp_full_k${K}_op${op}"
  84    compile_tau "$sim" fpga/tau/mlkem_acvp_tb.sv -P mlkem_acvp_tb.K=$K -P mlkem_acvp_tb.OP=$op 2>&1 | grep -v sorry || true
  85    [ -f "$sim" ] || { echo "VIRHE: $sim ei kaantynyt"; exit 1; }
  86  done
  87  
  88  echo "[2] NIST ACVP ML-KEM-$PSET + negatiivikontrollit (rinnakkain)..."
  89  for op in 0 1 2; do
  90    name="${OPS[$op]}"
  91    vec="fpga/tau/acvp/${name}_$PSET.txt"
  92    corrupt "$vec" "$TMP/${name}_bad.txt"
  93    run_case "sim/acvp_full_k${K}_op${op}" "$vec" pass "$name" > "$TMP/$name.log" &
  94    run_case "sim/acvp_full_k${K}_op${op}" "$TMP/${name}_bad.txt" fail "$name, turmeltu vektori" > "$TMP/${name}_bad.log" &
  95  done
  96  wait
  97  for name in "${OPS[@]}"; do
  98    cat "$TMP/$name.log" "$TMP/${name}_bad.log"
  99    grep -q VIRHE "$TMP/$name.log" "$TMP/${name}_bad.log" && FAILED=1
 100  done
 101  
 102  if [ "$FAILED" -ne 0 ]; then
 103    echo "ACVP ML-KEM-$PSET: VIRHEITA"
 104    exit 1
 105  fi
 106  echo "ACVP ML-KEM-$PSET: KeyGen 25, Encaps 25, Decaps 10; 3 negatiivikontrollia."
```
